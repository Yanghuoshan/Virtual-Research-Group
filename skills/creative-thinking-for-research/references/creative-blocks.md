# Creative Blocks and Unblocking

Diagnose the block before choosing a framework; the same technique applied to the wrong block wastes the session.

## Block Table

| Block | Symptom | Lens to apply |
|---|---|---|
| fixation | Cannot stop thinking about the problem one way | Representational change; force a different formalism |
| tunnel vision | All ideas come from the same subfield | Bisociation or structure-mapping; import from elsewhere |
| Self-censoring | Ideas dismissed as too unusual before exploration | Negation; defer evaluation until candidates exist |
| Incrementalism | Every idea is a small benchmark gain | Constraint manipulation; change the rules, not the parameters |
| Analysis paralysis | Too many options, cannot commit | Adjacent possible; what is feasible with current enablers |
| False dichotomy | Stuck choosing between two approaches | Janusian thinking; seek synthesis rather than selection |
| Unexplained result | Works but no mechanism | Abstraction laddering upward |
| Ungrounded theory | Elegant claim, no empirical anchor | Specialization under extreme constraints |

## Session Protocol

Effort allocation is guidance for depth, not a schedule to be committed elsewhere:

1. **Map the space:** list constraints of the current paradigm and mark them hard, soft or hidden; list recent enablers that change feasibility.
2. **Generate disruptions:** negate two or three soft or hidden constraints; build one cross-product matrix with a distant field; restate the problem in three ways (objective, formalism, agent).
3. **Deepen leads:** attach a structural analogy to each promising idea and extract its predictions; move each idea up and down the abstraction ladder; look for tensions that could be synthesized.
4. **Evaluate:** apply the two-sentence test and the validation checklist in [analogy validation](analogy-validation.md); keep plausible and rejected reformulations with reasons.

Generative mode precedes evaluative mode. Filtering during generation is the most common cause of a thin result.

## Working Rules

- Maintain a running list of every reformulation, including unlikely ones; rejected items are evidence of coverage and often recombine.
- Push for structural depth: when a mapping is surface-level, probe until mechanisms map or mark it speculative.
- Domain expertise comes from the supplied material and the requester; this skill supplies cognitive scaffolding, not domain facts.
- Sit with contradictions rather than resolving them quickly; a premature resolution usually reproduces the existing framing.

## Anti-Patterns

- Declaring the analogy sound because it is elegant; soundness requires a mapped mechanism and a prediction.
- Relaxing an assigned constraint (permissions, correctness, resource limits) and calling it transformational creativity.
- Turning the session into a plan: "next steps" are proposals returned to the core.
- Routing to another skill for evaluation or literature coverage; missing evidence returns as a blocker.
- Presenting the strongest reformulation as the adopted direction; selection belongs to the core.
